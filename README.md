# Little Steps · English

Una pequeña aplicación privada de tarjetas para practicar inglés desde el teléfono.

## Características

- Lecciones cortas y adultas, con instrucciones en español.
- Tarjetas táctiles con traducción, ejemplo y pronunciación por audio.
- Progreso guardado localmente en el dispositivo.
- Sin cuentas, analítica ni dependencias de servidor.
- Diseño responsive y preparado para “Añadir a pantalla de inicio” en iPhone.

## Publicar en GitHub Pages

1. Crea un repositorio **privado** en GitHub y sube el contenido de esta carpeta.
2. En el repositorio, abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Abre la URL generada en Safari y usa **Compartir → Añadir a pantalla de inicio**.

Para mantenerlo privado, recuerda que GitHub Pages público desde repositorios privados depende del plan de GitHub y de la configuración de la organización. Si Pages no permite una URL privada en tu cuenta, podemos cambiar el despliegue a Cloudflare Access, Netlify Identity o una VPN privada.
